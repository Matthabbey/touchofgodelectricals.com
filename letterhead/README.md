# Company letterhead

Two files:

- `Touch-of-God-Letterhead.docx` — the editable template. Open it in Microsoft Word (or Google Docs / LibreOffice), overwrite the sample letter in the body, and save. The header and footer repeat on every page automatically.
- `Touch-of-God-Letterhead.pdf` — a print-ready export of the same page, useful as a reference or for sending to a printer.

## Placeholders to replace

Everything in square brackets, plus the contact details in the header, is a placeholder:

| Where | Placeholder | Replace with |
| --- | --- | --- |
| Header | `+234 XXX XXX XXXX` (Phone and WhatsApp) | Real numbers |
| Header | `info@example.com`, `www.example.com` | Real email and website |
| Header | `[Street address, Area, Lagos, Nigeria]` | Office address |
| Footer | `[RC number]` | CAC registration number, or delete it |
| Body | `[Reference]`, `[Date]`, recipient block, `[Name]`, `[Title]` | Per letter |

To edit the header or footer in Word, double-click inside the header area at the top of the page.

## Design notes

- A4 portrait, 20 mm side margins. Brand colours match the website: red `#E31E24`, blue `#1F5FA8`.
- The header uses the real logo image. The wordmark on the right uses Arial Black because Poppins (the website font) is not installed on this computer. If you install Poppins, change the two header lines to it for an exact match.
- Body text is Calibri 11 pt. The script line uses Brush Script MT, which ships with Windows.
- No certifications, years of experience or client names are stated anywhere. Add them only if they are true.
